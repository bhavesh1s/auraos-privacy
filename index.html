2. Advertising & Campaign Attribution (Meta / Facebook Core SDK)

To support app distribution, measure user acquisition campaigns, and understand which marketing channels drive installs, AuraOS integrates the Meta (Facebook) Core Android SDK (com.facebook.android:facebook-core).

When you install and open the Application, the following standard advertising and diagnostic parameters are transmitted directly to Meta platforms:

  • Google Advertising ID (GAID / AD_ID): In accordance with Google Play's Advertising ID policy, the app declares the com.google.android.gms.permission.AD_ID permission. This allows Meta to attribute installs back to user-facing ad campaigns.
  • App Lifecycle Signals: App install, first open, app version (2.4-native), and device operating system version.
  • Technical Device Telemetry: Device manufacturer, hardware model, language locale, and carrier network classification.

This data is processed solely for Advertising/Marketing conversion measurement and Install Analytics. It is never sold by AuraOS to data brokers. For more details on how Meta processes attribution signals, please review the Meta Privacy Policy.

3. How to Opt-Out / Reset Your Advertising Identifier

You have complete control over your Android device's Advertising ID. You can reset or delete it at any time directly through your Android device settings:

  • Open your device Settings.
  • Navigate to Google → All Services (or Services) → Ads.
  • Tap "Delete advertising ID" to prevent any advertising SDK from accessing your identifier, or tap "Reset advertising ID" to cycle to a fresh identifier.

4. Local Device Storage (Android SharedPreferences)

All user settings and customizations—including your calibrated aim sensitivity numbers, HUD layout preference selections, active touch curves, and custom GFX reference presets—are stored strictly locally on your physical handset using Android's private SharedPreferences and application sandbox.

This configuration data never leaves your handset, is never uploaded to any remote cloud server, and cannot be read by third-party applications.

5. Permissions Utilized & Justifications

  • android.permission.INTERNET: Required to verify ad attribution signals via the Meta Core SDK and load hosted legal references when tapped by the user.
  • android.permission.ACCESS_NETWORK_STATE: Used by network libraries to check if an active internet connection is present before initiating network operations.
  • com.google.android.gms.permission.AD_ID: Required under Android 13+ (API 33+) to allow campaign install attribution via Google Play Services.
  • android.permission.VIBRATE: Used strictly to provide tactile haptic response during interactive button taps, slider adjustments, and module navigation.
